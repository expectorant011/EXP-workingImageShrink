# EXP-workingImageShrink

PNG · JPG · GIF(애니메이션 포함) 이미지를 브라우저에서 바로 30x30px로 리사이즈하거나, 원본 해상도를 최대한 유지하면서 500KB 이하로 압축하는 정적 웹 페이지입니다.

- 모든 처리는 브라우저 안에서만 이루어지며 파일을 서버로 전송하지 않습니다.
- 빌드 과정 없이 `index.html` 하나로 동작합니다.
- GitHub Pages: Settings → Pages → Source를 `main` 브랜치로 설정하면 바로 배포됩니다.

## 로컬 실행

`index.html`을 브라우저로 열기만 하면 됩니다.
